About the Mandelbrot Fractal

The Mandelbrot set is defined by the iterative complex polynomial equation:

Zn+1 = Zn2 + C

Starting with Z0 = 0, for each point C in the complex plane, we repeatedly calculate the sequence. If the magnitude of Z remains bounded (does not escape to infinity), the point belongs to the Mandelbrot set (shown in black).
